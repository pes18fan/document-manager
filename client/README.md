# client

Based on [SvelteKit](https://svelte.dev), uses [Tailwind CSS](https://tailwindcss.com)
for the styling.

## Developing

Make sure you have installed [`pnpm`](https://pnpm.io) and [`nodejs`](https://nodejs.org).

Install dependencies:

```sh
pnpm install
```

Start the development server:

```sh
pnpm run dev
```

Now, open `http://localhost:5173` on your browser to view the UI.
